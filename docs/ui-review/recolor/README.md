## Concrete differences from the "black + neon" control (UIUX_TEST_PROMPT criterion 10)

1. **Default surface is paper, not night.** Light "Obligasi" (`--field-1 #EEF2EC`) is the default and follows the
   system preference; dark "Brankas" is bottle green (`#0F1F19`), not near-black.
2. **No neon anywhere in the UI.** `#19F23A` survives only in the personal logo and the app/Dex icons; buttons, links,
   focus rings and chart lines use engraving-ink green `--primary #1D6A44` / jade `#5BC795`.
3. **No glow, halos or glowing field grid.** Depth comes from `--pane`/`--pane-2` tones and a 1 px `--edge`;
   `ui:audit` fails on `drop-shadow`, coloured blur shadows and decorative gradients (0 findings).
4. **Guilloche texture instead of a graph-paper grid** — deterministic security-printing lines at ≤ 6% opacity, only on
   the home hero (and the whitepaper cover), turned off in high-contrast mode.
5. **Constellation as ink dots.** Nodes are `--data` ink dots whose opacity encodes freshness, with solid/dashed status
   rings; the selected node is `--primary`; no breathing glow — only the one-time 1.2 s line draw.
6. **Provenance palette re-mapped to print inks:** data = ink green, AI = petrol blue, official quote = serif on cream
   paper, limitation = ochre, negative/emergency = brick red — all AA (≥ 4.5:1) on every surface in both themes
   (`tests/unit/contrast.test.ts`).
7. **Charts:** fixed 8-colour print palette per theme, 1.75 px lines, 12% area fill, `--edge` grid — no neon gradients.
